Amazon Sales Data Analysis
 # Project by: Mr. Omkar Kadam

## 📌 Project Overview
This project involves a comprehensive analysis of *Amazon Sales Data* to uncover trends, analyze consumer behavior, and provide actionable business insights. Using historical data, I performed Data Cleaning, Exploratory Data Analysis (EDA), and Visualization to identify key performance indicators (KPIs).

## 📊 Key Objectives
* *Sales Performance:* Analyze monthly and yearly sales growth.
* *Product Insights:* Identify the top-selling categories and products.
* *Customer Patterns:* Understand buying behavior across different regions and timeframes.
* *Profitability:* Examine profit margins across various segments.
