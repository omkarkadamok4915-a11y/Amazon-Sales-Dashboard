# 📊 Amazon Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project analyzes sales performance using Power BI.

## 📂 Dataset
- Source: Kaggle
- Records: 50000
- Fields: Sales, Profit, Region, Category

## 📈 Key Insights
- APAC Market generated highest revenue.
- Technology category has highest profit margin.

## 🛠 Tools Used
- Power BI
- DAX
- Data Cleaning
- Excel
